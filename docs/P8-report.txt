1. ROOT CAUSE ANALYSIS FOR PART A (WRONG / DIFFERENT DATABASE SYMPTOMS)
-------------------------------------------------------------------------------
The desktop and web modules BOTH read core/AppConfig -> DatabaseConfig, so the
desktop was already pointing at the configured DB (localhost:5433/flight_reservation
in app.json) when launched via scripts/run-desktop.ps1. However, three real bugs
caused the exact symptoms reported:

  (a) AppConfig lacked in-JVM port probing:
      Only the PowerShell launcher (pg-common.ps1) probed [configured, 5432, 5433].
      Running desktop directly (e.g. mvn javafx:run or IDE) skipped port probing.
      FIX: Added AppConfig.resolveWithPortProbe(...) in core so BOTH web and
      desktop share the exact single code path:
        SKY_ROYAL_DB_* > LAUNCH_DB_* > app.json > TCP probe [configured, 5432, 5433].
      Startup now logs ONE line (never the password):
        Sky Royal Desktop DB: <host>:<port>/<dbName> | upcomingFlights=<count>
      and binds DB name + upcoming flight count into the GlassTopBar brand tooltip.

  (b) "My bookings shows old Geneva bookings I never made":
      MyBookingsController.resolveUserId() had a hardcoded fallback `return 12L;`
      whenever currentUser was null (guest or dropped session), leaking demo user 12's
      bookings!
      FIX: Removed the 12L fallback completely. Guests now see a dedicated
      "Sign in to see your bookings" screen with a Sign in button and ZERO DB queries.

  (c) "Only one flight shows, nothing before 06:00":
      In core/sql/seed_flights_relative.sql and core/sql/seed_destinations_relative.sql:
      - Zero flights existed before 06:00 on ANY route (earliest was 06:00/06:30).
      - JNB->CPT had only 4 flights/day (none before 06:00 or after 18:00).
      - CPT->DUR, DUR->CPT, and all 10 destination routes had only 1 flight/day.
      FIX: Upgraded both rolling 14-day seed scripts so every popular route has
      6–10 departures/day spanning 05:10–21:15 across all 4 time bands, and every
      destination has 3+ flights/day for all 14 days.
